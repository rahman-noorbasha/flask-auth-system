# Flask Authentication System

A user authentication system built using Flask and SQLite.

## Features

- User Registration
- User Login
- User Logout
- Session Management
- Protected Dashboard
- SQLite Database Storage

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- Bootstrap

## Run Locally

```bash
pip install flask
python app.py
```

Open:

http://127.0.0.1:5000

## Learning Outcomes

- Authentication flow
- Session management
- SQLite integration
- Protected routes
- User login systems
